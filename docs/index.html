Journal 19 - 17-11-2025

Journal 19 - 17-11-2025

Veel geleerd vandaag, deze begrippen zijn langsgekomen. Ken je ze nu? Leg ze uit:

  • Basisregels voor goede CSS: Duidelijke, nette en overzichtelijke code schrijven zodat alles goed werkt en leesbaar blijft.
  • Onderdelen van CSS: Een selector (wat), properties (wat je aanpast), en values (de waarde van die aanpassing).
  • Kleuren goed kiezen: Kleuren gebruiken die goed leesbaar zijn, voldoende contrast hebben en passen bij je ontwerp.
  • Font family: Hiermee kies je welk lettertype een element gebruikt.
  • Font Face: Met @font-face voeg je je eigen lettertype-bestand toe aan een website.
  • Hyphens: Regelt of lange woorden automatisch worden afgebroken aan het einde van een regel.
  • Absolute length units: Lengtematen die altijd hetzelfde blijven, zoals px, cm, mm of in.

Hoe ga je het onderdeel over hoe lezen we toepassen op je opdracht

  • Door van boven naar beneden te kijken.

Ze durfden hardop te denken, waardoor ik inzicht kreeg in het gebruik van de interactie site, en ik heb geprobeerd ze zo min mogelijk te beïnvloeden of vragen tussendoor te beantwoorden.

User Test Resultaat 1 - Bronx

Bronx heeft mijn interactie site getest en het ging heel goed. Hij begreep wat hij moest testen en had amper begeleiding nodig. Hij gaf de volgende tips:

  • Een beschrijving input toevoegen zodat bezoekers kunnen begrijpen waar de boeken over gaan.
  • Een limiet instellen op het aantal woorden zodat er geen risico is dat te veel tekst wordt opgeslagen.

Voor de rest ging alles goed.

User Test Resultaat 2 - Clarisse

Clarisse heeft de interactie website getest en vond het heel duidelijk. Ze begreep wat ze moest doen en gaf de volgende tips:

  • Duidelijker aangeven waar de interactie te vinden is.
  • Een signaal geven wanneer de info van een boek succesvol is opgeslagen.

Verder ging alles goed en de interactie werd als duidelijk ervaren.

Verbeterpunten / conclusie

  • Beschrijving input toevoegen voor boeken, met limiet op aantal woorden.
  • Duidelijker aangeven waar gebruikers de interactie kunnen vinden.
  • Feedback geven wanneer informatie succesvol is opgeslagen.
  • Blijven oefenen met observatie en notities maken tijdens user tests om kleine details vast te leggen.
